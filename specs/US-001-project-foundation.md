# Goal
Create the runnable project skeleton for a local Windows desktop app.

# Requirements
- Define Python 3.12 package metadata and development/runtime dependencies.
- Create the proposed package boundaries, startup wiring, a minimal PySide6 window, and pytest configuration.
- Document setup and launch commands; do not add processing features.

# Acceptance Criteria
- The application opens and closes a minimal window on Windows.
- Package imports and test discovery work from a documented development setup.
- No transcription, LLM, or media job starts on launch.

# Dependencies
- Approved product and architecture documentation; explicit activation of this story.

# Tests / Definition of Done
- Run package/startup smoke checks and relevant pytest checks.
- Verify window launch/close; record results and update setup documentation.
